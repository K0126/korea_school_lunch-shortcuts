# 전국 초·중·고 급식 확인 단축어 위젯

전국에 있는 초등학교, 중학교, 고등학교의 중식(점심) 메뉴를 확인할 수 있는 단축어 위젯입니다. 우선 이 위젯을 제작하는 데 필요한 API를 제공해 준 [교육부](https://www.moe.go.kr/main.do?s=moe)와 [한국교육학술정보원](https://www.keris.or.kr/main/main.do)에 감사드립니다.

API는 [나이스 교육정보 개방 포털](https://open.neis.go.kr/portal/mainPage.do)에서 제공됩니다.

## 다운로드 링크

**iOS만 가능합니다.**

> 오늘 점심 다운로드 링크:
>
> https://www.icloud.com/shortcuts/e714494ccfce4394acbe57437bf21136

## 단축어 설치 방법

### 1. 단축어 다운로드

위 링크에 접속한 후 단축어 설정을 눌러줍니다.

### 2. 지역 코드 입력

본인의 학교가 위치하는 지역의 지역 코드를 넣어줍니다. (첫 글자 알파벳은 대문자입니다.)

```
서울: B10
부산: C10
대구: D10
인천: E10
광주: F10
대전: G10
울산: H10
세종: I10
경기도: J10
강원도: L10
충청북도: M10
충청남도: N10
전라북도: P10
전라남도: Q10
경상북도: R10
경상남도: S10
제주도: T10
```

### 3. 학교 이름 입력

학교 이름을 띄어쓰기 없이 풀네임으로 적어준 후 하단의 단축어 추가를 눌러주시면 됩니다.

## 단축어 사용 방법

### 1. 위젯

1. 홈 화면에서 바탕화면을 길게 눌러준 후 좌측 상단에 위치한 + 버튼을 눌러줍니다.
2. 상단에서 단축어를 검색한 후 오늘 급식 위젯을 추가해 줍니다.
3. 위젯 클릭 시 오늘 점심 급식 메뉴가 출력됩니다.

### 2. 앱

1. 단축어 앱에서 오늘 점심 단축어의 우측 상단 점 3개를 눌러줍니다.
2. 상단의 오늘 점심 텍스트 옆 화살표를 눌러 홈 화면에 추가를 눌러줍니다.
3. 앱 실행 시 오늘 점심 급식 메뉴가 출력됩니다.

## 안내

### 1. 최초 실행

처음 실행하시는 경우 팝업에서 허용을 눌러주셔야 합니다.

### 2. 급식 정보 업데이트

학교에 따라 급식 정보 업데이트가 느린 곳은 사용이 불가할 수 있습니다. (출력이 안 나올 경우)

메뉴명 옆 숫자들은 알레르기 유발 식재료 번호들입니다.

초·중·고 모두 불러오는 거라 일단은 중식(점심)만 지원합니다. 조만간 고등학교용 조식, 석식도 업데이트할 예정입니다.

# Korean School Lunch Menu Shortcut Widget

An iOS Shortcut widget that allows users to check daily lunch menus for elementary, middle, and high schools across South Korea.

First, I would like to thank the [Ministry of Education](https://www.moe.go.kr/main.do?s=moe) and the [Korea Education and Research Information Service (KERIS)](https://www.keris.or.kr/main/main.do) for providing the API required to develop this widget.

The API is available through the [NEIS Open API Portal](https://open.neis.go.kr/portal/mainPage.do).

## Download

**Available for iOS only.**

> Today's Lunch Shortcut:
>
> https://www.icloud.com/shortcuts/e714494ccfce4394acbe57437bf21136

## Installation Guide

### 1. Download the Shortcut

Open the download link above and tap **Set Up Shortcut**.

### 2. Enter Your Region Code

Enter the regional education office code corresponding to the location of your school.

The first letter of the code must be uppercase.

```
Seoul: B10
Busan: C10
Daegu: D10
Incheon: E10
Gwangju: F10
Daejeon: G10
Ulsan: H10
Sejong: I10
Gyeonggi-do: J10
Gangwon-do: L10
Chungcheongbuk-do: M10
Chungcheongnam-do: N10
Jeollabuk-do: P10
Jeollanam-do: Q10
Gyeongsangbuk-do: R10
Gyeongsangnam-do: S10
Jeju-do: T10
```

### 3. Enter Your School Name

Enter your school's full official name in Korean without spaces.

Once entered, tap **Add Shortcut** at the bottom of the screen to complete the installation.

## How to Use

### 1. Using as a Widget

1. Press and hold an empty area on your iPhone's Home Screen, then tap the **+** button in the upper-left corner.
2. Search for **Shortcuts** in the widget gallery and add the Today's Lunch widget.
3. Tap the widget to display today's school lunch menu.

### 2. Using as an App

1. Open the Shortcuts app and tap the three dots in the upper-right corner of the Today's Lunch shortcut.
2. Tap the arrow next to the shortcut name at the top and select **Add to Home Screen**.
3. Launch the shortcut from your Home Screen to display today's school lunch menu.

## Important Notes

### 1. First-Time Permissions

When running the shortcut for the first time, you must tap **Allow** on the permission pop-up.

### 2. Meal Information Updates

Some schools may take longer to update their meal information.

If the shortcut does not display a menu, the school's meal information may not have been updated yet.

### 3. Allergen Information

The numbers displayed next to each menu item indicate ingredients that may cause allergic reactions.

```
1. Eggs
2. Milk
3. Buckwheat
4. Peanuts
5. Soybeans
6. Wheat
7. Mackerel
8. Crab
9. Shrimp
10. Pork
11. Peaches
12. Tomatoes
13. Sulfites
14. Walnuts
15. Chicken
16. Beef
17. Squid
18. Shellfish (including oysters, abalone, and mussels)
19. Pine Nuts
```

### 4. Supported Meal Types

Since this shortcut supports elementary, middle, and high schools nationwide, it currently provides lunch menus only.

Support for breakfast and dinner menus for high schools is planned for a future update.
